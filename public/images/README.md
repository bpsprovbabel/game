# 🏛️ Panduan Mengganti Logo Instansi / Kegiatan
### Game Tarik Tambang Otak (Battle of Brains Online)

Game ini saat ini menggunakan **Logo Resmi BPS Provinsi Kepulauan Bangka Belitung** (`logo.svg`).

Jika Anda ingin mengganti dengan logo BPS daerah lain, logo instansi lain, atau logo acara/kepanitiaan tertentu kapan saja:

---

## 🚀 Langkah Cepat Mengganti Logo:

1. **Siapkan file logo baru Anda** (format `.png` berlatar belakang transparan sangat disarankan, atau format vektor `.svg`).
2. **Ubah nama file** menjadi:
   - **`logo.png`** (rekomendasi utama untuk file gambar PNG)
   - atau **`logo.svg`** (jika memiliki file vektor SVG)
3. **Simpan / Timpa (Overwrite)** file tersebut langsung ke dalam folder ini:
   ```
   public/images/
   ```
4. **Refresh halaman game di browser (`F5`)**.
5. **Selesai!** Logo baru Anda akan otomatis langsung tampil di:
   - Header Menu Utama / Lobby Permainan.
   - Header Layar Monitor Host (Monitor Pertandingan).

---

## 📐 Rekomendasi Format & Resolusi:
- **Rasio**: Landscape (melebar horizontal) agar pas dengan tata letak header.
- **Resolusi**: Minimal lebar 400 piksel (misalnya `500 x 150` piksel) berlatar belakang transparan.
