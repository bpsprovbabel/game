========================================================
PANDUAN MENGGANTI LOGO INSTANSI / PERUSAHAAN
GAME TARIK TAMBANG OTAK
========================================================

Jika Anda ingin mengganti logo BPS Provinsi Kepulauan Bangka Belitung
dengan logo lain kapan saja di masa mendatang:

1. Siapkan file logo baru Anda (format PNG, SVG, atau JPG).
2. Simpan atau timpa (overwrite) file tersebut di folder ini dengan nama:
   - logo.png (rekomendasi untuk gambar PNG transparan)
   - atau logo.svg (untuk vektor SVG)

3. Refresh halaman game (F5) di browser.
   Logo baru Anda akan langsung otomatis tampil di Menu Utama
   dan di Layar Monitor Host!

Ukuran proporsional yang disarankan:
- Rasio Landscape (Melebar), resolusi minimal 400 x 100 piksel.
